PrepNova Admin

Runs entirely in your phone's browser. Nothing is sent anywhere.

1. Master passphrase

A long phrase only you know (for example 4 or 5 random words). It makes the secret keys for your questions. Use the same phrase every time. If you forget it, you must re-lock your questions and issue new codes.

Check code: — (it must be identical every time you type the same phrase)

2. Make access codes

  1. Tap Copy updated codes.json.
  2. On GitHub, open your repo, then codes.json, then the pencil (edit).
  3. Select all, paste, and tap Commit changes.
  4. Wait about a minute, then the new codes work.

3. Lock a subject's questions

Paste your questions as a JSON list. The result is a locked file that only students with a code can open.

answer is the position of the correct option, starting from 0 (A=0, B=1, C=2, D=3).

  1. On GitHub: Add file, Create new file.
  2. File name: data/biology.enc.json
  3. Paste the copied content and commit.
